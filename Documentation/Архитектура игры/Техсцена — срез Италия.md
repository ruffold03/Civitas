## Что это за документ

Спецификация **первой технической 3D-сцены** для вертикального среза: [[Италия]], эпоха [[Античность]], один город (ориентир — **Рим**, основа `latium_hills`). Сцена проверяет **цельность картинки и связку с снимком партии**, а не полный визуальный объём среза.

Общие художественные правила — в [[Визуальный стиль]]. Логика карты и клеток — в [[Клетки и карта]]. Числа симуляции — в [[Вертикальный срез — Италия]]. Этот файл **не меняет** правила хода и не добавляет механик.

---

## Зачем сцена

**Гипотеза:** изометрический город в стилизованном реализме читается на рабочем приближении: видны и **планировка**, и **силуэты зданий**, без постоянной сетки.

**Критерий успеха (техсцена закрыта), когда:**

1. Участок 12×12…18×18 клеток собран в Godot, камера изометрическая, сетка скрыта в обзоре и видна в «строительстве».
2. Минимум **три типа зданий** из среза стоят на **реальных координатах** из `buildings[].cells` снимка Рима.
3. Ландшафт по `terrain_at` (равнина, холм, берег, река, море — хотя бы три типа на участке).
4. Дорога и вода читаются на фоне застройки.
5. При смене `status` здания (`working` / `idle` / `building`) меняется **только картинка** (дым, стройка, затухание), сим не трогаем.
6. На целевом ПК сцена держит **60 FPS** при ~30 инстансах зданий + окружение (см. бюджет ниже).

**Не входит в техсцену:**

- все 18 зданий среза и все три географические основы;
- карты соседей (ИИ) в 3D;
- жители, транспорт, дым, LOD — **вторая волна** после закрытия пункта 1–5;
- замена основного UI (`game/main.tscn` / `board.gd`) — сцена живёт отдельно или как вкладка/превью, пока не стабилизируется пайплайн.

## Связь с кодом (сейчас)

| Источник | Использование в 3D |
|----------|-------------------|
| `CivSliceScenario.opening_snapshot("rome")` | Стартовая расстановка для отладки |
| `buildings[]` | `type`, `cells`, `status`, `timer` → модель и состояние |
| `roads[]` | клетки дороги → плитка/грунт |
| `map_cells` | залежи (опционально, декаль/иконка) |
| `foundation` = `latium_hills` | генерация рельефа и воды |
| `CivGeoSlice.terrain_at(x, y, foundation)` | материал/меш клетки |

**Правило:** визуальный слой **только читает** снимок после расчёта хода ([[Игровое состояние]]). Ошибка отрисовки не влияет на партию.

Предлагаемая точка входа в проекте (имена можно уточнить при реализации):

- `game/city_view_3d.tscn` — корневая сцена;
- `game/city_view_3d.gd` — синхронизация с `Dictionary` снимка;
- `art/italy/classical/` — модели и материалы региона;
- `art/italy/classical/buildings/<type_id>.glb` — одна сцена на тип (не общая мешка с подменой текстуры).

## Участок карты

Для техсцены достаточно **не всей** карты 18×18.

| Параметр | Значение |
|----------|----------|
| Размер (клетки) | **12×12** в центре стартовой зоны Рима (расширяемо до 18×18) |
| Origin сетки | как в симе: клетка (0,0) = угол участка |
| Высота | холм +1 ступень по `hill`, равнина 0, берег −0.5 у воды (допуск ±0.25 для читаемости) |
| Вода | полоса **реки** (Тибр) и при необходимости **моря** на юго-востоке — по `terrain_at` |
| Сетка | шаг 1 world unit = 1 клетка; изометрический поворот 45° / камера ортографическая |

Много-клеточные здания: якорь — **минимальные** `x` и `y` среди `cells`; модель масштабируется или используется вариант «2×1», «2×2», «4×1» по `area` из каталога.

## Камера

По [[Визуальный стиль]], раздел 6:

| Параметр | Техсцена v0 |
|----------|-------------|
| Проекция | ортографическая, изометрия |
| Повороты | **4** направления, шаг 90° (клавиши Q/E или кнопки UI) |
| Зум | ограниченный диапазон (обзор квартала ↔ улица) |
| Панорама | перетаскивание мышью, без влияния на сим |
| Сетка | `visible = false` по умолчанию; `true` в режиме `build` / `prepare` / `road` / `survey` |

Клик по земле: raycast → `(x, y)` → тот же контракт, что у `board.cell_pressed` (для будущей интеграции).

## Набор контента v0 (обязательный)

Три здания из [[Вертикальный срез — Италия]] — минимум из [[Визуальный стиль]], §10:

| id | Роль | Заметки для модели |
|----|------|---------------------|
| `domus` | жильё | 1 клетка, терракотовая крыша, светлая штукатурка |
| `sawmill` | производство | 2 клетки, дерево, дым при `working` |
| `town_hall` | общественное | 1 клетка, ратуша / базилика, сильный силуэт |

**Окружение v0:**

| Объект | Реализация |
|--------|------------|
| Дорога | 1 клетка, `road` в снимке — плитка или утопленная колея |
| Деревья | 3–5 инстансов на `plain`/`hill`, один меш + вариации поворота/масштаба |
| Вода | плоскость/шейдер с лёгкой анимацией UV, без симуляции физики |

**Материалы:** общие шейдеры игры, палитра **Средиземноморье** (светлый камень, терракота, зелень) — [[Визуальный стиль]], §4.1.

## Состояния здания на экране

Читать из снимка, не выдумывать:

| `status` | Отображение |
|----------|-------------|
| `working` | полная модель, рабочие эффекты (дым, звук опционально) |
| `idle` | та же модель, эффекты выключены, лёгкое «затухание» (saturation ↓) |
| `building` | стройка: леса / полупрозрачный каркас, `timer` → прогресс-бар или стадии |

Эпоха и регион: для техсцены только `classical` + `italy`; поле `era` в снимке не меняет модели до Альфы.

## Производительность (ориентир)

| Метрика | Цель техсцены |
|---------|----------------|
| FPS | ≥ 60 на средней конфигурации (1080p) |
| Draw calls | ≤ 120 на участке 12×12 с 25 зданиями (инстансинг деревьев/дорог) |
| Полигоны | ≤ 15k на кадр для зданий v0 (низко-поли + нормали) |
| Тени | одно направленное солнце, мягкие тени, без каскадов на весь 18×18 |

Повторяющиеся объекты — `MultiMeshInstance3D` где возможно ([[Визуальный стиль]], §8.4).

## Пайплайн ассетов

1. **Блокаут** в Blender: кубы по клеткам, экспорт scale 1 unit = 1 cell.
2. **Модель** — стилизованный реализм, силуэт важнее мелочи.
3. Экспорт **glTF 2.0** (.glb), оси Y-up, центр основания в углу клетки якоря.
4. В Godot: `import` → сцена здания; коллизия — упрощённый `StaticBody3D` для raycast.
5. Именование: `domus_classical_italy.glb`, id в коде = `domus`.

LOD и атласы — после того, как на сцене одновременно ≥ 40 зданий.

## Чеклист приёмки

- [ ] Сцена открывается из редактора и загружает снимок Рима с диска или из `CivSliceMatch.new_game`.
- [ ] Все стартовые здания (дома, колодец, ратуша, ферма, лесопильня) имеют модель или явный плейсхолдер-меш с подписью типа.
- [ ] Рельеф совпадает с типами местности симе (визуально: река не строится, гора не занята зданием).
- [ ] Камера: 4 поворота, зум, панорама.
- [ ] Режим «строительство»: сетка видна, в обзоре скрыта.
- [ ] Смена `status` у лесопильни меняет дым/затухание без перезапуска партии.
- [ ] Документирован путь добавления четвёртого здания (один glb + строка в реестре).

## Этапы после техсцены

1. Подключить сцену к **основному экрану** (кнопка «3D» / split view) — опционально.
2. Расширить реестр до **всех 18** типов среза (плейсхолдеры допустимы).
3. Отдельный пресет для **Неаполь** / **Тарент** (берег, гавань) — те же правила, другие материалы воды/берега.
4. Карта соседа в 3D — только просмотр, тот же `ai_cities[id]` снимок.
5. Альфа: единая художественная система для **трёх стран** и четырёх эпох ([[Дорожная карта]]).

## Решения (зафиксировано)

- Первая 3D-сцена — **Рим**, `latium_hills`, античность.
- Обязательный визуальный минимум — **domus, sawmill, town_hall** + дорога, деревья, вода.
- Симуляция остаётся в 2D-сетке до стабильной интеграции; 3D не блокирует закрытие среза по механикам.
- Региональная идентичность — **отдельные модели**, не texture swap на одной мешке.
