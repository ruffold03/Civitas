
Победа вертикального среза: крупный италийский полис.

| Поле | Значение |
|------|----------|
| Идентификатор | `population_italy_slice` |
| Имя | Численность |
| Когда проверяется | каждый ход, после шага населения |
| Условие | численность не меньше **500** |

Поражение — 0 человек. На ходе **150** без победы побеждает город с большей численностью; при равенстве — больше [[Деньги|денег]] в казне.

Отличается от прототипа ([[Численность]] — порог 100).

Связи: [[Вертикальный срез — Италия]], [[Каталог среза Италия]].
