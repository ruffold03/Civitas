Жильё. Одна хижина даёт пять мест. Теснота и простор считаются общим правилом, не этой карточкой.

| Поле | Значение |
|------|----------|
| Идентификатор | `hut` |
| Вид | здание |
| Эпохи | [[Древность]] |

| Форма | одна связная область по сторонам клеток |
| Местность | [[Земля]] |
| Дорога | не требуется |
| Стоимость | 10 [[Дерево\|дерева]] |
| Срок строительства | 1 ход |
| Содержание | 0 |
| Входы | нет |

| Постоянные эффекты | нет |

Хижина забирает дерево у [[Кострище|кострища]], [[Поле|поля]] и [[Загон|загона]] и сама еду не даёт.
