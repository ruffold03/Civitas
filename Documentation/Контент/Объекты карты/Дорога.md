
Связь клеток. Не входит в лимит 18 зданий среза.

| Поле | Значение |
|------|----------|
| Идентификатор | `road` |
| Вид | дорога |
| Имя | Дорога |

Стоимость: **2 [[Дерево|дерева]]**. Срок: **1 ход**. Одна клетка.

Обязательна для [[Рынок]], [[Порт]], [[Форум]], [[Храм]] **вне** стартовой зоны. Окраинные постройки должны быть связаны с [[Ратуша|ратушей]] дорогой, если карточка требует дорогу.

Связи: [[Вертикальный срез — Италия]], [[Строительство]].
