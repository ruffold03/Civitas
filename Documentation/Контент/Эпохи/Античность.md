
Единственная эпоха вертикального среза Италии. В полной игре — вторая эпоха после [[Древность]].

| Поле | Значение |
|------|----------|
| Идентификатор | `classical` |
| Имя | Античность |
| Порядок | 2 |
| Визуальная стадия | плейсхолдер среза, без изометрии |
| Условие перехода | в срезе не задано |

В срезе открыто по сравнению с прототипом [[Древность|древности]]: [[Деньги]] после [[Монета]], столица и [[Престиж среза]], торговля между городами, изучение чанков и подготовка клеток. [[Туризм]] выключен. Экология не считается.

Здания эпохи — в [[Контент/Постройки/Античность|Постройки/Античность]]. [[Колодец]] как в древности. Остальные шесть пар древность→античность: [[Дом]], [[Лесопильня]], [[Каменоломня]], [[Площадь]], [[Пашня]], [[Ферма]].
