## Что это за документ

Победа — главная цель игры. К ней стремится каждый город.

Условия конкретного типа здесь не расписываются. Они лежат в карточке этой победы.

---

## Семь типов

В игре семь типов побед:

| Тип           | Карточка                                  |
| ------------- | ----------------------------------------- |
| Научная       | [[Научная]]                               |
| Культурная    | [[Культурная]]                            |
| Экономическая | [[Экономическая]]                         |
| Промышленная  | [[Промышленная]]                          |
| Лояльность    | [[Контент/Победы/Лояльность\|Лояльность]] |
| Экологическая | [[Экологическая]]                         |
| Столица       | [[Страна]]                                |

У каждого типа свои условия. У победы «столица» уже задано одно: город должен быть столицей во всех эпохах, кроме [[Древность|древности]]. Остальные условия столицы и условия прочих побед задают карточки.

Отдельной победы наследия нет. То, что раньше было победой наследия, входит в культурную победу.

В прототипе другая победа, не из этого списка: [[Численность]], поселение выросло до ста человек. После неё партия не продолжается.

## Одна победа на партию

Игрок сам выбирает, к какой победе стремиться. Этот выбор ничего не закрывает: город может идти к одной победе, а выполнить условие другой. Чужой город может победить типом, который игрок не выбирал. Свой выбор чужой город делает сам: ту победу, которую, по его оценке, сможет достичь первым. Гонку задаёт [[Конкуренция]].

Условие победы проверяется каждый ход.

В партии случается одна победа. Как только победил любой город страны, партия завершена. Игрок может продолжить ту же партию: достраивать город и играть дальше. Новых побед уже не будет.

Если в один ход условие выполнили несколько городов, победителя выбирают дополнительные факторы. Один из них — престиж. Полный набор факторов и формула здесь не заданы.

Если за 500 ходов ни один город не победил, победитель считается по очкам. Формула очков пока не задана. Это тоже одна победа партии: после неё можно продолжить игру без новых побед.

## Стиль игры

Победа задаёт тактику и стратегию. Разные победы дают разный геймплей. Ниже примеры стиля, не условия карточек.

- Научная: школы, библиотеки, высокая грамотность, изучать технологии первым.
- Культурная: театры, музеи, парки и наследие города.
- Промышленная: цеха, заводы, добыча ресурсов и материалов, производство техники.
- Экономическая: надёжные банки, полная казна, торговые пути, биржи, порты.
- Лояльность: низкая преступность, внутренние органы, медицина, качество жизни.
- Экологическая: меньше загрязнений, больше парков и заповедников, возобновляемые источники энергии, ветряки и солнечные панели вместо угольных заводов.
- Столица: держать звание столицы. Подробности в [[Страна]].

Списки не закрыты.
